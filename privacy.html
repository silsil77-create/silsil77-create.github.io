対象: kaigai_hyoten uploader（YouTube チャンネル「海外組の評点と反応まとめ」@kaigai_hyoten の運営者が使う個人用ツール）

使う情報

このツールは、運営者本人の Google アカウントで許可を得て、次のことだけを行います。

  • 運営者が作った動画・字幕・サムネイルを、運営者の YouTube チャンネルにアップロードする
  • 運営者のチャンネルの動画の再生回数などの視聴データを読み取る

ほかの人のアカウントやデータにはアクセスしません。

保存と共有

  • Google から受け取るログイン情報（アクセストークン）は、運営者の PC の中にだけ保存します。
  • 取得した情報を第三者に販売・提供・共有することはありません。広告や外部サービスへの送信にも使いません。
  • 許可は、Google アカウントの設定（https://myaccount.google.com/permissions）からいつでも取り消せます。

Google API サービスの利用

このツールによる Google API から受け取った情報の使用と移転は、制限付き使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。YouTube API サービスを利用しており、YouTube 利用規約 と Google プライバシーポリシー が適用されます。
